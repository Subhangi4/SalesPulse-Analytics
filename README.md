# 📊 SalesPulse Analytics

Interactive Sales Performance Analytics Dashboard for analyzing sales data and tracking key business KPIs.

## 📌 Overview

This project includes an Excel dashboard and an interactive HTML dashboard to visualize sales performance and generate meaningful business insights.

## 📊 Key Metrics

- Total Sales
- Profit & Profit Margin
- Total Orders
- Customers
- Average Order Value
- Product Performance
- Order Status
- Regional Performance

## 🛠️ Tools Used

- Microsoft Excel
- HTML
- CSS
- JavaScript
- Data Analysis & Visualization

## 📁 Files

- `SalesPulse_Analytics_Dashboard.xlsx` — Dataset & Excel Dashboard
- `SalesPulse_Analytics_Dashboard.html` — Interactive HTML Dashboard
